# Lean proofs of optimal packings

Machine-checked **optimality** results for catalogue records: the record's container is proven to be the
smallest possible, not only feasible. (The feasibility of 532 records is verified separately in
`docs/research-2026-10-16-generalization/formal`.) Same Lean toolchain and Mathlib revision as that project.

```
lake exe cache get && lake build && lake env lean Axioms.lean
```

| Module | Content |
|---|---|
| `PackingOptimality/Basic.lean` | Packings of congruent convex bodies (any rigid motion, disjoint interiors) in any finite-dimensional Euclidean space; affine isometries preserve volume; the **volume bound** `n · vol K ≤ |s|^d · vol C`; the self-packing corollary `n ≤ |s|^d`; restriction `s(m) ≤ s(n)` for `m ≤ n`; the **common-point lemma** (if every copy inside `s • C` contains a fixed point in its interior, no two copies fit). |
| `PackingOptimality/Cubes.lean` | **Cubes in a cube**, every dimension `d ≥ 1` and every `k ≥ 1`: `k^d` unit cubes need side exactly `k` (`cubes_in_cube_optimal`; grid upper bound, volume lower bound). Catalogue instances `cubincub_n08`, `cubincub_n27`, `cubincub_n64`, `c8inc8_n16`, `hc5inhc5_n32`. The plateau `s(n) = 2` for `2 ≤ n ≤ 2^d`, conditional on the cube centre lemma (`cube_plateau_of_centre_lemma`). |
| `PackingOptimality/CubeCentre.lean` | **The cube centre lemma in dimension 3** (`centre3`): a unit cube inside a cube of side `s < 2` contains its centre. Via the matrix inequality `2(Σ|aᵢ| − 1) ≤ Σ|aᵢ|(|bᵢ| + |cᵢ|)` for orthogonal matrices (`core`; a zero-entry identity plus a minimiser argument on the circle of rotations). Hence **side 2 is optimal for 2 ≤ n ≤ 8 cubes in a cube** (`cubincub_plateau`, instances `cubincub_n02`–`cubincub_n07`). |
| `PackingOptimality/NearAxis.lean` | Hiroaki Hosono's near-axis step, ported unchanged from [wand125/square-packing](https://github.com/wand125/square-packing/tree/main/problems/cubes-n-dim/lean) (MIT; see the file header): a polar-decomposition reduction of Lemma F near an axis to Lemma F one dimension down (`near_region`). |
| `PackingOptimality/LemmaF4.lean` | **Lemma F in dimension 4** (`lemmaF4`). Near an axis: `near_region` with Lemma F in 3D (`lemmaF3`, from `CubeCentre.core`). Elsewhere: a zero-sum and Cauchy–Schwarz bound (`pair_bound`), then three one-variable cubic inequalities and an 81-way case split (`far_poly`). |
| `PackingOptimality/CentreGeneral.lean` | From Lemma F in dimension d to the cube centre lemma in dimension d, for every d (`centre_of_lemmaF`). |
| `PackingOptimality/Tesseracts.lean` | **Side 2 is optimal for 2 ≤ n ≤ 16 tesseracts in a tesseract** (`centre4`, `c8inc8_plateau`, instances `c8inc8_n02`–`c8inc8_n15`). |
| `PackingOptimality/OctBands.lean`, `PackingOptimality/OctInCube.lean` | **Two octahedra in a cube: side √2 is optimal** (`octincub_n02`, new). Lemma O (`lemmaO`): Σᵢ |⟨ρᵢ, σ⟩|(1 − ‖ρᵢ‖∞) ≤ 1 for orthogonal rows; octahedron centre lemma (`centre_oct`); explicit packing (`octPacking`). The band lemmas are generated by `scripts/optimality/lean_gen/`. |
| `PackingOptimality/FacetWidth.lean`, `PackingOptimality/TetInCube.lean` | The facet-width lemma, any dimension (`centre_of_facet_width`). **Two tetrahedra in a cube: side 2√2/3** (`tetincub_n02`, new). |
| `PackingOptimality/TetInOct.lean` | **Two tetrahedra in an octahedron: edge 2/√3** (`tetinoct_n02`, new). Facet-width lower bound; the packing reflects the tetrahedron by the Householder map sending (1,1,1)/√3 to e₃. |
| `PackingOptimality/TetInDod.lean` | **Two tetrahedra in a dodecahedron: edge √2(√5 − 1)/3** (`tetindod_n02`, new). Facet-width lower bound with the dodecahedron inside the ball of its circumradius; the tetrahedron-in-cube packing sits in the dodecahedron's inscribed cube. |
| `PackingOptimality/BallBound.lean`, `PackingOptimality/Polytopes4.lean` | The two-ball lemma for hypercube and cross-polytope containers, any dimension. **Two 16-cells in a tesseract (3√2/4), two 24-cells in a tesseract (3√2/2), two 24-cells in a 16-cell (3)** (`c16inc8_n02`, `c24inc8_n02`, `c24inc16_n02`, new). |
| `PackingOptimality/Prisms.lean` | **Triangular prisms in a triangular prism**: `k^3` unit prisms need scale exactly `k` (`prisms_in_prism_optimal`; tiling by translates and point reflections of the unit prism, via a shear of the right-triangle prism; volume lower bound). Catalogue instances `pr3inpr3_n08`, `pr3inpr3_n27`, `pr3inpr3_n64`. |

`Axioms.lean` prints the axioms of every main theorem; CI (`.github/workflows/lean-optimality.yml`)
fails unless all of them depend only on `propext`, `Classical.choice` and `Quot.sound`.

Status of every low-n record: [`docs/OPTIMALITY.md`](../docs/OPTIMALITY.md).
